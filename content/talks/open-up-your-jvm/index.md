This talk was part of the Kansas City Java User Group on May 15, 2025.

When building and deploying Java applications, gaining insight into their performance characteristics is crucial. This talk will share methods and tools to help you gain a deeper understanding of what's happening in your JVM. You'll learn about improvements in how you can utilize these available tools in your development and evaluate performance issues (CPU, memory, and network) with your Java production workloads.
